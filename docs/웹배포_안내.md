# 웹 서버판: 다운로드 없이 사이트에서 쓰기 (fly.io)

윈도우판과 **같은 코드**를 서버 모드(`CONTOUR_SERVER=1`)로 fly.io 에 띄웁니다.
사무소 사람들은 `https://ua-contour-model.fly.dev/app` 같은 주소를 브라우저로 열어 바로 씁니다(설치·다운로드 없음).

| 파일 | 하는 일 |
|---|---|
| `Dockerfile` | 서버 이미지: 파이썬 3.13 + `requirements-server.txt` + `contour_ai`, `python -m contour_ai serve` |
| `fly.toml` | fly.io 설정: 앱 이름, 도쿄(nrt), 메모리 4GB, 안 쓰면 자동으로 꺼짐, 사무소용 제한값 |
| `.github/workflows/deploy.yml` | `main` 에서 '자동 시험'이 통과하면 fly.io 에 새 판 올리기 (토큰 없으면 건너뜀) |
| `.github/workflows/ci.yml` 의 `docker` 작업 | PR 마다 이미지를 만들어 띄우고 화면·예시 도엽이 나오는지 확인 |

## 처음 한 번 하는 일 (약 15분)

### 1. fly.io 계정
1. https://fly.io 가입(사무소 계정 권장). 결제 카드 등록이 필요합니다.
2. PC 에 flyctl 설치 — Windows PowerShell: `pwsh -Command "iwr https://fly.io/install.ps1 -useb | iex"`
3. `fly auth login`

### 2. 앱 만들기
저장소를 받은 폴더에서:
```
fly apps create ua-contour-model
```
이름이 이미 쓰이고 있다고 나오면 다른 이름으로 만들고, `fly.toml` 맨 위 `app = "..."` 도 같은 이름으로 바꿉니다. 이 이름이 사이트 주소가 됩니다.

### 3. 인증키 넣기 (선택, 서버에만 저장됨)
서버판에서는 화면에 키를 넣는 칸이 없고 **서버 환경변수의 키를 모두가 같이 씁니다.** 저장소·코드에는 절대 쓰지 않습니다.
```
fly secrets set VWORLD_KEY=브이월드키 DATA_GO_KR_KEY=공공데이터포털키 -a ua-contour-model
```
필요하면 `SEOUL_KEY`, `SAFEMAP_KEY`, `VWORLD_DOMAIN` 도 같은 방식. 브이월드 키의 서비스 주소에는 사이트 주소(`https://ua-contour-model.fly.dev`)를 적습니다.

### 4. 자동 배포 토큰
```
fly tokens create deploy -a ua-contour-model
```
나온 값을 GitHub 저장소 **Settings → Secrets and variables → Actions → New repository secret** 에 이름 `FLY_API_TOKEN` 으로 넣습니다.

### 5. 첫 배포
GitHub **Actions → 웹 서버 배포 → Run workflow** (또는 PC 에서 `fly deploy`). 5~10분 뒤 `https://ua-contour-model.fly.dev/app` 이 열리면 끝.
그다음부터는 `main` 에 합칠 때마다 자동으로 새 판이 올라갑니다.

## 쓰는 법 (사무소 사람)
- `https://ua-contour-model.fly.dev/app` 접속 → 수치지도 zip(과 대지 DXF)을 끌어다 놓기 → 범위 고르기 → 만들기 → 결과 **내려받기**(zip).
- 처음 들어갈 때나 한동안 아무도 안 썼으면 서버가 깨어나느라 10~20초 걸립니다.
- 작업은 서버 전체에서 한 번에 하나씩 순서대로 돕니다(동시에 누르면 대기 줄).
- 올린 파일·결과는 2시간 동안 안 쓰면 지워집니다. 결과는 바로 내려받아 두세요.

## 윈도우판과 다른 점
- PC 경로 입력·폴더 열기·정밀도로지도 폴더 지정은 안 됩니다(파일은 화면에 올려서).
- `.skp` 는 서버에 스케치업이 없어 만들지 않고 `.dae`(스케치업에서 가져오기) 로 받습니다.
- 인증키는 서버 키 하나를 같이 씁니다.

## 제한값 바꾸기 (`fly.toml` 의 `[env]`)
| 값 | 지금 | 뜻 |
|---|---|---|
| `CONTOUR_RUNS_PER_DAY` | 100 | 한 인터넷 주소(IP)가 하루 만들 수 있는 횟수. 사무소는 모두 같은 IP 로 보이므로 넉넉히 |
| `CONTOUR_MAX_SIDE` | 1000 | 모델 한 변 최대(m) |
| `CONTOUR_JOB_MINUTES` | 15 | 한 작업 최대 시간 |
| `CONTOUR_KEEP_MINUTES` | 120 | 쉬면 파일을 지우는 시간 |
| `CONTOUR_MAX_UPLOAD_MB` | 200 | 파일 하나 최대 크기 |

## 비용·보안 메모
- 아무도 안 쓰면 서버가 꺼지므로(`auto_stop_machines`) 켜져 있는 시간만큼만 냅니다. 4GB 메모리 서버 요금은 fly.io 요금표(https://fly.io/pricing)에서 확인하고, 대시보드에서 사용량을 보세요.
- 주소를 아는 사람은 누구나 쓸 수 있습니다(사무소 키·서버 시간을 씀). 외부에 주소를 알리지 말고, 막아야 하면 비밀번호 기능을 따로 더하세요.
- 서울시 가로수 자료(공공누리 4유형, 상업적 이용 금지)가 내장돼 있습니다. 사무소 내부 검토용으로만 쓰고 유료·외부 서비스로 열지 마세요.
