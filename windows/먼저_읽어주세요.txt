콘타 모델 만들기 - Windows 설치 없는 버전 (v{VERSION}, {DATE})

필요한 것: 64비트 Windows 10 또는 11. 따로 설치할 프로그램은 없습니다. 인터넷 없이도 돌아갑니다
(위성영상 녹지·브이월드 항공사진 같은 선택 기능만 인터넷이 필요합니다).

1. zip 파일을 오른쪽 클릭 → "모두 압축 풀기"로 푼 뒤, 풀린 폴더에서 실행하세요 (zip 안에서 바로 실행하면 안 됩니다).
2. "콘타모델 실행.bat"을 더블클릭합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면: 추가 정보 → 실행
3. 브라우저에 화면이 열립니다. 수치지도 2.0(SHP) zip을 끌어다 놓고, 범위를 고른 뒤 "모델 만들기".
4. 결과는 C:\Users\내이름\콘타모델 폴더에 저장됩니다 (화면의 "결과 폴더 열기" 버튼).
   이 판은 스케치업 파일만 만듭니다: 이 PC에 스케치업이 있으면 model_sketchup.skp까지 바로,
   없으면 model_sketchup.dae(스케치업 가져오기)와 만들기 자료. 3D 프린트도 스케치업 파일에서 내보내면 됩니다.
   (model.glb 는 화면 3D 미리보기용입니다.)
   사이트판과 달리 횟수 제한·크기 제한·자동 삭제가 없습니다. 지난 결과는 직접 지우세요.

다른 컴퓨터로 옮길 때: 이 폴더(콘타모델_윈도우)를 통째로 USB나 클라우드로 복사하면 그대로 실행됩니다.
폴더 위치와 이름(한글·띄어쓰기 포함)은 아무렇게나 바꿔도 됩니다. 단, 폴더 안의 python 폴더는 지우거나 옮기지 마세요.

검은 창을 닫으면 프로그램이 꺼집니다.
자세한 설명은 사용법_전체.md (메모장으로 열림)를 보세요.
오류가 나면 검은 창이나 화면의 "진행 기록" 탭을 캡처해 보내 주세요.

인증키(선택): 브이월드·공공데이터포털 키는 화면의 자료 칸에 직접 넣습니다. 이 프로그램 안에는 들어 있지 않습니다.

정밀도로지도(선택): 국토지리정보원에서 받은 정밀도로지도 zip을 풀지 말고 한 폴더에 모아 두면 노면표시를 그 자료로 그립니다.
화면 '자료 파일 → 정밀도로지도 폴더'에 한 번 적거나, 비워 두면 다운로드·바탕 화면·D 드라이브 등에서 스스로 찾습니다.
정밀도로지도는 재배포 금지 자료라 이 프로그램에 들어 있지 않습니다. 각자 받아야 합니다.
